## 🚀 How to Run & Preview

### Method 1: Direct in Browser
Double-click `index.html` or run in terminal:
```bash
open /Users/alexmih/claudecode/portfolio/index.html
```

### Method 2: Local HTTP Server (Python)
```bash
cd /Users/alexmih/claudecode/portfolio
python3 -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.

## ✨ Features Included
- **Dark / Light Theme Toggle** with automatic persistence in `localStorage` and system preference detection.
- **Category Filtering** for Career Track (Corporate Finance & M&A, Operations & Logistics, Software Development).
- **Interactive Modals** for in-depth abstracts and methodologies of authored research papers.
- **One-Click Clipboard Actions** for email and phone numbers.
- **Print / PDF Export Stylesheet** (`@media print` optimized so pressing the print icon generates a clean executive resume).
- **Mobile Responsive** with sliding navigation drawer and touch-friendly controls.
- **Zero External JS Dependencies** for maximum speed and security.

## 🌐 Free Instant Deployment Options

### GitHub Pages
1. Push this folder to a GitHub repository (e.g. `alexandru-portfolio`).
2. Go to **Settings > Pages** and select `main` branch root.
3. Your site is live at `https://<username>.github.io/<repo>/`!

### Vercel / Netlify
1. Drag and drop the `portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
2. Live in less than 30 seconds with a free SSL custom domain!
